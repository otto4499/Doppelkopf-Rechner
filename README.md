# Doppelkopf-Rechner

Punktezähler für Doppelkopf als Web-App fürs iPhone.

## Funktionen
- 4–7 Spieler mit frei wählbaren Namen; pro Runde wird gewählt, wer aussetzt (rotiert automatisch weiter)
- Gewinner antippen, Spielwert über ein Drehrad einstellen
- **Bock**-Taste: 1× drücken = ×2, 2× drücken = Doppelbock ×4 (bleibt aktiv, bis sie wieder ausgeschaltet wird)
- **Solo-Faktor** ×2 bis ×5: 1 Gewinner (Solist gewinnt) oder 3 Gewinner (Solist verliert); der Solist bekommt/zahlt den 3-fachen Wert
- Kontostand je Spieler (Summe immer 0) inkl. Umrechnung in Euro (Standard 1 Punkt = 10 Cent, in den Einstellungen änderbar)
- Liste aller Runden, jede Runde nachträglich bearbeitbar oder löschbar
- Verlauf aller Spieleabende mit Gesamtstand über alle Abende
- Backup exportieren/importieren, funktioniert offline, heller und dunkler Modus

## Veröffentlichen mit GitHub Pages
1. Im Repository auf **Settings → Pages** gehen
2. Unter *Build and deployment* bei **Source** „Deploy from a branch“ wählen
3. Branch `main` (bzw. den Branch mit diesem Code) und Ordner `/ (root)` auswählen, **Save**
4. Nach 1–2 Minuten ist die App erreichbar unter `https://<benutzername>.github.io/Doppelkopf-Rechner/`

## Auf dem iPhone installieren
Seite in **Safari** öffnen → **Teilen** → **Zum Home-Bildschirm**.

Die Daten werden lokal auf dem Gerät gespeichert.
